# Content Surface Guidance

## Homepage — intensity 100%

Use the strongest display treatment here.

Allowed:

- XL display type
- large hard shadows
- asymmetric grid
- one or two overlapping framed elements
- bright primary accent

Still preserve conventional navigation and clear CTAs.

## Portfolio index — intensity 90%

Project discovery should feel graphic and memorable.

Use:

- large project titles
- curated card colors
- featured-card span changes
- screenshot framing
- strong hover/press behavior

## Project detail — intensity 70%

Hero can remain strong. Narrative sections should become calmer.

Avoid putting every screenshot, paragraph, metric, and code block inside identical shadowed cards.

## About — intensity 70%

Blend personality and readability.

A strong self-introduction/statement can be expressive; biography and supporting content should read normally.

## CV — intensity 60%

Prioritize scanability and chronology.

Use borders and bold section titles, but keep dense experience content compact and professional.

## Blog index — intensity 70%

Use the brand language for article discovery without turning every card into a poster.

## Blog article — intensity 35%

The article itself is a reading interface.

Strong treatment is reserved for:

- title/header
- metadata
- callouts
- code blocks
- diagrams/images
- navigation

Normal paragraphs remain on calm surfaces with predictable spacing.

## Forms — intensity 50%

Use structural borders and clear button behavior. Keep field alignment, labels, help text, and errors conventional.

## Navigation — intensity 80%

Navigation may be a signature visual object, but it must remain instantly understandable and stable across pages.
