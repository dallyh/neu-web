# Source Notes

Primary inspiration/reference:

- https://neubrutalism.com/

The kit distills the site's documented design grammar into an original, project-specific system for a portfolio/blog/CV. Key ideas adapted at a high level include:

- thick structural borders
- zero/near-zero corner radius
- hard offset shadows with zero blur
- flat saturated accents on a neutral structural base
- bold display typography paired with calm body typography
- tokenized visual primitives
- structured rather than random asymmetry
- physical lift/press interaction behavior
- stronger expression on portfolio/marketing surfaces than on dense reading/functional surfaces
- WCAG-aware contrast, focus, and hit-target handling

This file is explanatory context only. `docs/DESIGN.md` is the project source of truth.
